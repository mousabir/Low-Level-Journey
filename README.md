# Low-Level Journey

This repository contains my work from the 1337 Piscine, including C exercises, shell exercises, and the BSQ project.

## Shell

### Shell00
Introduction to the Unix/Linux command line. Working with files and directories, file permissions, links, basic commands, and understanding how to interact with the operating system through the shell.

### Shell01
Going further with shell commands and scripting. Practicing command combinations, pipes, text processing, file searching, and automating tasks using shell scripts.

## C Programming

### C00 — C Fundamentals
Starting with the basics of C programming. Learning how to write functions, display characters and numbers, use loops and conditions, and build simple logical operations.

### C01 — Pointers
Introduction to pointers and memory addresses. Understanding how to access and modify values through pointers, work with arrays, and pass addresses to functions.

### C02 — Strings and Character Manipulation
Working with characters and strings in C. Learning how strings are represented in memory, how to manipulate them, and how to implement character-checking and string-conversion functions.

### C03 — String Manipulation
Working with more advanced string operations, including comparison, concatenation, and searching. Understanding how to work with string boundaries and memory safely.

### C04 — Data Conversion
Converting between different data representations. Working with string-to-integer conversion, displaying numbers, handling different number bases, and understanding how numeric values are represented.

### C05 — Recursion and Algorithms
Introduction to recursive functions and mathematical problem-solving. Working with factorials, powers, Fibonacci numbers, square roots, prime numbers, and algorithmic problems.

### C06 — Command-Line Arguments
Understanding how a program receives information when it starts. Working with `argc` and `argv`, processing command-line arguments, and building programs that behave differently depending on their inputs.

### C07 — Dynamic Memory Allocation
Learning how to allocate memory dynamically using `malloc` and release it using `free`. Working with dynamically created arrays and strings, memory ownership, and building functions that return allocated memory.

### C08 — Headers and Structures
Understanding how to organize C programs using header files, function prototypes, structures, and `typedef`. Learning how to define custom data types and organize code across multiple files.

### C09 — Makefile and Static Libraries
Moving from individual C files to building reusable libraries. Learning how to compile source files into object files, create static libraries, use Makefiles, and manage compilation with different rules.

### C11 — Function Pointers
Understanding function pointers and how functions can be passed as arguments to other functions. Working with callbacks, applying functions to arrays, and building more flexible and reusable code.

## Projects

### BSQ — Biggest Square
A project focused on finding the largest possible square in a map without obstacles.

The program works with a map containing empty spaces and obstacles. The objective is to identify the largest square that can fit in the map without covering any obstacles and then display the resulting map.

This project involves file handling, map parsing, algorithms, and problem-solving.
